## Règle importante — Check in @ Work

**À chaque fois qu'un JMS ou un chantier est attribué à quelqu'un sans que le
C@W soit précisé, il faut le demander avant de sortir les PDF.**
Techniquement, le code C@W se précise via `caw="NOM_DU_CODE"` directement sur l'entrée
J()/X() du dict PLANNING — c'est cette même valeur qui alimente le PDF Check in @ Work.
Le tableau secrétariat ne doit jamais partir avec une case C@W devinée.

Formule type : « Pour le JMS xxxxxx de mardi, quel Check in @ Work ? »

## Règles permanentes du planning

- Uniquement les dossiers **confirmés**. Les dossiers « à planifier » restent hors PDF.
- **Deux PDF, un seul exemplaire de chaque** : le planning chantier et le Check in @ Work
  pour le secrétariat, même modèle, mêmes couleurs. Les deux sont générés à partir d'une
  SEULE source de données (dict PLANNING, avec le code C@W attaché à chaque prestation
  via `caw=`) — il n'y a plus de dict séparé à maintenir à la main, donc plus de risque
  que les deux documents divergent.
  **On ne garde qu'une semaine à la fois** : dès qu'une nouvelle semaine démarre, on arrête
  de régénérer celle qui est terminée.
- **(Depuis S39, 07/09/2026)** Un seul fichier PDF par document et par semaine — **plus de
  copie doublon avec underscores**. Le planning chantier va dans
  `Claude/Planning/Grille Planning/` (dossier déplacé/renommé par l'utilisateur), le
  Check in @ Work reste dans `Claude/Planning/Check-in @ Work/`.
- 1 page A4 paysage, 1 colonne = 1 jour, noms rappelés dans chaque colonne.
- Colonne samedi ajoutée seulement s'il y a au moins une prestation ce jour-là.
- Case grisée = rien de confirmé. Absences affichées dans la case avec leur motif
  (CONGÉ, MALADIE, FORMATION, RÉCUP, ABSENT, EN ATTENTE).
- Demi-journées et nuits : badges MATIN / APRÈS-MIDI / JOURNÉE / NUIT 21H00–04H30.
- Giuseppe Caruso : pas de ligne propre, apparaît en pastille dans l'équipe où il est placé.
  Pas d'adresse mail — il ne reçoit pas l'envoi groupé.
- Numéros JMS cliquables vers monday.com. Recherche dans le **nom** de l'élément
  ET dans la colonne **Référence** (certains numéros n'y sont que là).
- Mise à jour de Monday en parallèle : date prévue et personnes, côté Soufflage
  ou Jointage selon qui fait le travail. **Sauf BTO, jamais modifié.**
- Horodatage automatique (date + heure belge) à chaque génération.
- Fichiers : `Planning WILBOW - S<sem> - <jours> <mois> <année>.pdf`
  et `Check in at Work - S<sem> - <jours> <mois> <année>.pdf`
- Case « barrée » (personne partie / plus disponible pour le reste de la période) :
  grande barre diagonale grise sur toute la cellule, chantier retiré. Motif `BARRE` dans le script.
